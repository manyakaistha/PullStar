# Changelog

## 1.0.1 — 2026-11-07

- Fix the live trail preview showing blue night skies with red and blue swapped (warm/orange). Final images and videos were unaffected.

## 1.0.0 — 2026-11-01

- First PullStar desktop release, with a dark alignment workspace and the finalized tapered star-trail icon.
- Automatic and manual wobble correction, RAW previews, and cancellable processing.
- Aligned-frame export without creating trails, plus selectable image and video formats.
- Standalone Apple Silicon macOS packaging with Python, FFmpeg, and processing dependencies.
- Included MCP server for diagnostics, settings comparison, previews, image export, and background jobs.
- Runtime backend discovery, startup checks, isolated writable app storage, and single-instance desktop behavior.

The macOS binary is ad-hoc signed; Apple notarization is pending developer signing credentials.
