Expand description

How a number is written, read back, and applied while being edited.

Owned by crate::DragValue, and by crate::Slider and crate::RangeSlider for the numbers they show beside the rail.

Fields§

§prefix: Atoms<'a>

Shown before the number, e.g. "x: ".

§suffix: Atoms<'a>

Shown after the number, e.g. a unit.

§min_decimals: usize

Show at least this many decimals.

§max_decimals: Option<usize>

Show at most this many decimals, and round values to it.

§custom_formatter: Option<NumFormatter<'a>>

Turns a value into text. Default: crate::style::NumberFormatter.

§custom_parser: Option<NumParser<'a>>

Turns text back into a value. Default: accepts plain decimal numbers.

§update_while_editing: bool

Apply each keystroke while typing, rather than on enter.

Source

pub fn binary(self, min_width: usize, twos_complement: bool) -> Self

Set custom_formatter and custom_parser to display and parse numbers as binary integers. Floating point numbers are not supported.

min_width specifies the minimum number of displayed digits; if the number is shorter than this, it will be prefixed with additional 0s to match min_width.

If twos_complement is true, negative values will be displayed as the 2’s complement representation. Otherwise they will be prefixed with a ‘-’ sign.

§Panics

Panics if min_width is 0.
