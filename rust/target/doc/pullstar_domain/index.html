Validated domain contracts shared by every PullStar crate.

This crate owns the units, coordinate conventions, image descriptors, job state machine and error vocabulary that the Python implementation currently spreads across config.py, modules/transform.py and backend/services/job_manager.py.

Conventions frozen here:

  • Pixel coordinates are f64 and refer to pixel centers. The first pixel center is (0.0, 0.0), matching OpenCV’s convention in the Python code.
  • Affine2 stores the OpenCV 2x3 matrix in row-major order and forward maps source pixel coordinates onto reference (destination) pixel coordinates, i.e. dst = M * src.
  • Angles are radians unless a type name says otherwise.
  • Progress is monotonic within a job and clamped to 0.0..=1.0.

These invariants are checked at construction so that downstream crates can rely on them without repeating validation.
